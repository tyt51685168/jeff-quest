# Jeff Quest

A 5–10 minute pixel RPG résumé. Walk through Jeff Tu's life — NTUST, Deloitte, Far EasTone and Ho Chi Minh City — talk to people, inspect objects and collect 7 badges.

一款 5–10 分鐘的像素 RPG 履歷。走過台科大、勤業眾信、遠傳與胡志明市，和人物對話、調查物品，收集 7 枚徽章。

## Controls 操作

| | Desktop 電腦 | Mobile 手機 |
| --- | --- | --- |
| Move 移動 | Arrow keys / WASD | D-pad |
| Inspect / talk 調查、交談 | Space / Enter / Z | A |
| Run 跑步 | Hold Shift | Hold B |
| Menu 選單 | Esc / M | MENU button |

No time to play? Choose **"Just show me the résumé"** on the title screen.
沒空玩？標題畫面選「直接看履歷」。

## Tech

A single static `index.html`: HTML canvas, vanilla JavaScript, Web Audio for the original chiptune soundtrack. No build step, no dependencies (fonts from Google Fonts).

## Local preview

```bash
npx serve .
# or
python3 -m http.server
```
